# 猜拳必勝魔法

使用 Python 與 UV 啟動的本機攝影機猜拳遊戲。第一次使用時，請先為剪刀、石頭、布各拍攝至少 12 張手勢樣本；訓練完成後即可開始對戰。遊戲會倒數 3、2、1，接著播放「剪刀、石頭、布」語音，再辨識玩家手勢，顯示電腦必勝的手勢與「你輸了」4 秒，再自動倒數開始下一局。

## 環境需求

- Windows、Python 3.11 以上
- [UV](https://docs.astral.sh/uv/)
- 支援攝影機的最新版網頁瀏覽器

## 安裝與啟動

在專案資料夾執行：

```powershell
uv sync
uv run python app.py
```

伺服器會在 `http://127.0.0.1:8000` 啟動並嘗試開啟瀏覽器。若瀏覽器未自動開啟，請手動前往該網址，並允許攝影機存取。按 `Ctrl+C` 可停止伺服器。

## 使用方式

1. 按「開啟攝影機」，並允許瀏覽器使用攝影機。
2. 按「顯示 AI 偵測」可在攝影機畫面上顯示手部關節與連線；按「關閉 AI 偵測」可隨時隱藏，不會停止遊戲。
3. 將手放在畫面中央框框內，在明亮、背景簡單的環境下依序比出剪刀、石頭、布，各拍攝至少 12 張；可改變手勢角度和位置以增加辨識樣本。
4. 訓練完成後按「開始對戰」，倒數 3、2、1 後會播放「剪刀、石頭、布」語音，接著遊戲會先定位手部，再以手部關鍵點辨識手勢，並以圖示、手勢名稱和「你輸了」顯示電腦必勝出拳 4 秒，之後自動倒數並開始下一局。按「停止對戰」可結束。
5. 按「清除訓練資料」可移除目前瀏覽器中的樣本並重新訓練。

## 隱私與辨識說明

攝影機影像及手部關鍵點只在瀏覽器記憶體中處理，不會上傳。首次使用會從 jsDelivr CDN 載入 MediaPipe 程式、WebAssembly 與手部辨識模型；模型下載後由瀏覽器本機執行。每張訓練樣本只儲存正規化後的手部關鍵點特徵，不儲存原始影像，並保存在該瀏覽器的本機儲存空間。換瀏覽器、清除網站資料或使用無痕視窗時，需重新訓練。

此專案以 MediaPipe 手部關鍵點定位手掌，再比對本機訓練樣本中的 3D 世界座標關節距離；使用公尺單位的世界座標，可避免攝影畫面寬高比例影響手勢特徵，並降低背景變化的干擾。辨識效果仍會受遮擋、光線和手勢角度影響；請確保手掌完整入鏡並拍攝不同角度的樣本。新版關鍵點特徵格式會要求重新訓練一次。

本機伺服器會對回應設定 `Cache-Control: no-store`，避免瀏覽器使用舊版的專案程式。
