# 猜拳必勝魔法

使用 Python 與 UV 啟動的本機攝影機猜拳遊戲。第一次使用時，請先為剪刀、石頭、布各拍攝至少 8 張手勢樣本；訓練完成後即可開始對戰。遊戲會辨識玩家手勢，並出必勝的手勢。

## 環境需求

- Windows、Python 3.11 以上
- [UV](https://docs.astral.sh/uv/)
- 支援攝影機的最新版網頁瀏覽器

## 安裝與啟動

在專案資料夾執行：

```powershell
uv sync
uv run python app.py
```

伺服器會在 `http://127.0.0.1:8000` 啟動並嘗試開啟瀏覽器。若瀏覽器未自動開啟，請手動前往該網址，並允許攝影機存取。按 `Ctrl+C` 可停止伺服器。

## 使用方式

1. 按「開啟攝影機」，並允許瀏覽器使用攝影機。
2. 將手放在畫面中央框框內，在明亮環境下依序比出剪刀、石頭、布，各拍攝至少 8 張；可改變手勢角度以增加辨識樣本。
3. 訓練完成後，比出手勢並按「辨識手勢並猜拳」。辨識成功時，遊戲會顯示辨識結果與電腦必勝的出拳。
4. 按「清除訓練資料」可移除目前瀏覽器中的樣本並重新訓練。

## 隱私與辨識說明

攝影機影像只在瀏覽器記憶體中處理；每張樣本會轉成手勢特徵並儲存在該瀏覽器的本機儲存空間，不會上傳影像。換瀏覽器、清除網站資料或使用無痕視窗時，需重新訓練。

此專案使用本機手勢樣本與影像梯度特徵進行輕量辨識，不是通用手部辨識模型。辨識效果會受光線、背景和攝影機影響；請保持背景簡單、手勢位於框框中央並拍攝多種角度的樣本。
